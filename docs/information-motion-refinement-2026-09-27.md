# Information surface motion refinement

Scope: the shared visitor information surface and its existing controls. Published website motion, content selection, provider work and history state remain separate.

The surface already used stable canonical React keys, `AnimatePresence` with `popLayout`, position-only layout projection and measured real height. This refinement coordinates those primitives with one stable `LayoutGroup`, marks the fixed information frame as a layout root, and separates fast content opacity from spatial movement: 160 ms for arrival opacity, 320 ms for arrival travel, 380 ms for reflow and 180 ms for departure. New content mounts immediately; no sequential entrance, per-item delay or typewriter effect is added. Back and forward retain their existing mirrored directions.

Width changes previously restarted a full height tween whenever the measured content reflowed. During an already-animating width change, the frame now follows measured real height directly; independent height changes retain a bounded tween. Text and video are never scaled. The existing geometry/opacity observer and Motion start/completion bookkeeping still decide when a display has settled; shorter timings do not manufacture a receipt. Intermediate-frame browser acceptance must verify the width/height path, absence of blank frames, and truthful settled state.

`usePlatformReducedMotion` subscribes to the operating-system media query with a stable server snapshot. The installed Motion 13.2 hook samples on mount, so this subscription is necessary for live preference changes. Information regions/grids and shared motion primitives respond in the same visit; an active measured-height animation stops at its destination when reduced motion is enabled. `MotionHeight` passes its requested duration as `visualDuration`, because a spring's existing `visualDuration` overrides `duration`.

The broad `InterfaceMotion` wrapper retains Motion's automatic reduced-motion policy for registered components with their own transitions. Only the measured information-region and grid-item elements bypass Motion's mount-time cache; their live hook owns their transforms and opacity, and their descendants immediately regain the automatic policy. Neither boundary remounts media when the preference changes. Other legacy registered components' live preference behavior is not claimed to be migrated in this pass.

Existing history, dismissal and local-gallery buttons keep their 44 px targets, labels, focus outlines and native activation. Fine-pointer hover shifts only a history arrow by 2 px, press feedback stays inside the icon, and color feedback takes 160 ms. Touch does not receive sticky hover behavior. Reduced motion removes the control transforms and transitions. These decorative controls do not participate in display receipts.

Installed 13.2 source was checked where it differs from current documentation. Scroll-linked movement and SVG drawing were not added to factual content because neither helps read or act on the current result.
