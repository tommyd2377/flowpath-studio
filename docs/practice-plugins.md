# Practice plugins

On a private waveform, open **Plugins**, install one or more activities, and save the draft. Open **Preview draft**, start voice, and ask for an activity. The display appears when voice opens it. The carousel can switch between activities already opened in the same conversation. Hiding a display keeps voice connected.

| Plugin | Try saying |
| --- | --- |
| Quiz / Evaluation | “Quiz me on Franklin’s electricity experiments.” |
| Guided Lessons | “Give me a guided lesson on Franklin’s lightning rod.” |
| Flashcards | “Make flashcards about Franklin’s inventions.” Then ask to reveal the answer. |
| Interview Practice | “Run a mock interview for a museum guide.” |

All four activities can use general knowledge without uploads. For Quiz, Guided Lessons or Flashcards, add “using my documents” to request verified passages from your ready private Knowledge documents. General-knowledge activities have no document citations. Quiz grades are practice feedback with a bounded point total. Interview Practice uses generic role scenarios and the learner’s answers. GPT-Live can handle simple spoken clarifications directly. Activity display updates go through the existing GPT-6 Luna tool.

Activity state lives in the current browser conversation and clears when the call ends. These opt-in capabilities are available to the owner in private previews. Published and paid preview sessions do not advertise the practice tool. No new provider, billing path, external action, or independent search endpoint is required.
