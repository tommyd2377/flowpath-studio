# Practice plugins

On a private waveform, open **Plugins**, apply one or more activities, and save the draft. Open **Preview draft**, start voice, and ask for an activity. The display appears when voice opens it. The carousel can switch between activities already opened in the same conversation. Hiding a display keeps voice connected.

| Plugin | Try saying |
| --- | --- |
| Quiz / Evaluation | “Quiz me on Franklin’s electricity experiments using my documents.” |
| Guided Lessons | “Give me a guided lesson on Franklin’s lightning rod.” |
| Flashcards | “Make flashcards about Franklin’s inventions.” Then ask to reveal the answer. |
| Interview Practice | “Run a mock interview for a museum guide.” |

Quiz requires ready private Knowledge documents and uses verified passages. Grading is model-generated coaching with a bounded point total. Lessons and Flashcards can use authorized sources when available. Interview Practice is coaching with generic role scenarios.

Activity state lives in the current browser conversation and clears when the call ends. These opt-in capabilities are available to the owner in private previews. Published and paid preview sessions do not advertise the practice tool. No new provider, billing path, external action, or independent search endpoint is required.
