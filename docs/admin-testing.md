Ordinary homepage demos reserve three minutes. Existing counters are preserved; local unmetered calls do not gain customer credit or alter financial settlement.

With the switch off, the admin follows regular visitor/member/payment rules. Limits appear as ordinary status or purchase requirements, with no admin modal. Signed-out users and other accounts keep the normal flow and never receive this switch or an override.

Hosted modes retain the 15-minute conversation maximum, global budget/capacity and independent deadline. All modes retain uncertain-cleanup guards, current account authority, ownership, microphone cleanup and cancellation. Mode changes apply to new conversations.
