# Product direction

Start with one centered waveform and a natural conversation. Keep the main application small and let future plugins contain their own domain complexity.

The first milestone uses GPT-Live's own knowledge and one short instruction prompt. New conversations start fresh. Later an owner can save instructions, enable plugins and share a waveform; the owner pays for visitors subject to individual and aggregate caps. News remains a standalone example and can become the first built-in plugin later.

Prove the voice experience before adding accounts, memory, public trials or plugin infrastructure. Preserve useful existing visuals, accessibility and reliable media cleanup.
