# Website import

In **Knowledge → Import a website**, enter a domain or public HTTPS URL and choose **Find website pages**. Select available pages, discover their images, and import selected knowledge. Discovery, original-image downloads and the deterministic legacy repair do not use AI. Connected knowledge interpretation uses one existing owner attempt, without automatic retries.

## A fresh native website

Studio proposes an editable FlowPath website using controlled sections, cards, galleries and navigation. Source metadata, headings, contact information and hours inform the proposal. Bounded stylesheet inspection can suggest a brand accent and discover background images; stylesheets are discarded after extraction. There is no source-layout copying mode, HTML iframe, font capture or source script execution.

The [website generation contract](website-generation.md) defines the reusable content brief and source-record checks. Connected imports remove source-page/bookkeeping entities before merge, preserve substantive content and evidence, and fail visibly if only source containers were returned. Reimports propose retirement of unchanged legacy copies while retaining publisher edits. The newest pending proposal opens first.

Review knowledge and design, save corrections, then **Apply to draft**. **Publish** is separate. The native visitor website renders independently of assistant availability; the shared published-content reader accesses approved native content. Raw source captures and provenance remain private.

A validated but incomplete website interpretation is labeled as a partial proposal, including when every selected page was captured. Review its reported gaps or conflicts and explicitly acknowledge the incomplete import report before Apply; this acknowledgement does not approve unsupported assertions or publish the site.

If a publisher has selected Editorial, Showcase or Clarity in **Branding**, applying a website interpretation preserves that template, its independent customizations and existing opening selections. The design review points to Branding for template styling. Switching templates does not require another import or model call; [the template guide](templates-and-source-lifecycle.md) documents the controls and compatibility behavior.

## Original-quality photos

Discovery recognizes explicit original/full-image attributes, lazy images, responsive image candidates, metadata images, inline backgrounds and bounded external stylesheet backgrounds. For each reference, the downloader compares decoded pixel dimensions across up to eight referenced variants and three bounded original candidates for Wix, Squarespace and WordPress/CDN images and retains the largest successfully decoded file's exact original bytes privately. Original and lazy references remain candidates even when responsive descriptors claim a larger size. Unavailable candidates fall back to supported alternatives. This is the best available discovered image within the limits, not a guarantee of recovering an inaccessible original or reversing source compression.

Supported formats are still JPEG, PNG and WebP. Each image has a 10 MB download limit, a 40-million-pixel decode limit and a shared 45-second candidate-download budget. Unsupported formats and failed imports are reported. Separate metadata-free display WebP copies (up to 2,000 pixels) and 480-pixel thumbnails serve the website; they do not replace the retained original. Images use the existing private storage and current-publication authorization boundaries.

Selections, successful file IDs and errors are saved between visits. Download up to 20 selected images at a time. Duplicate file hashes reuse stored assets. Review captions, alternative text, actual-subject/example roles, entity association and photo-library/lead/logo placement. **Apply reviewed photos to draft** creates a reversible media revision; originals and already reviewed knowledge remain intact. Import or explicitly exclude unresolved images before applying. Publishing remains separate.

The legacy website places reviewed general site photos in small groups between content sections. The three new templates compose reviewed albums according to their own layout and require an explicit lead/opening selection for a hero image. Explicit item associations remain attached to their items. Photo groups keep their album labels and do not imply an association with adjacent content. OCR source screenshots are not automatically promoted to opening photography.

## Parsing, repair and limits

Structural HTML extraction removes repeated navigation, forms and footer boilerplate from semantic input while retaining a private source capture. Factual footer prose such as contact details, hours and policies remains bounded source content; contradictory body/footer statements are retained for review. Footer boundaries also prevent those facts from becoming part of the final priced offering. Explicit price groups, size variants and adjacent price qualifications can become deterministic offering proposals. Reimport reconciliation preserves publisher edits and suppresses matching records. An older import can use **Prepare source-based website repair (no AI)** to propose removal of unchanged raw-page/bookkeeping duplicates. Unsupported fields remain pending publisher decisions; a proposal does not establish inventory, reservations or executable ordering capabilities.

Discovery reports up to 100 pages, fetches at most 12 pages initially, and allows 24 selected pages. It reads the starting page first and prioritizes its primary navigation links over body links and sitemap-only pages for the initial selection. Account, checkout, cart/basket and ordering paths, including numbered variants, are excluded. Saved page selections remain unchanged when rediscovering the same website. Initial discovery exposes up to 60 image references; selected-page discovery merges up to 100. Stylesheet discovery reads at most 16 distinct linked files, each up to 1 MB, with a shared 45-second budget. It does not follow stylesheet imports. Truncation and unavailable-resource notes require review. Public HTTPS fetching checks DNS and redirects against private destinations. Robots exclusions and unavailable HTML disable page selection with a reason. JavaScript-only pages, inaccessible originals and unsupported image formats may require manual migration.

Existing historical source-layout references are ignored by the native runtime and retired when the draft is next updated. Their private immutable historical files are not deleted automatically. No draft edit changes a publication until the publisher publishes it.
