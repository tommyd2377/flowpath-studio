# Legacy FlowPath branding

This archive preserves historical FlowPath branding from the older life-decision and AI planning app. The primary artwork was recovered byte-for-byte from FlowPath commit `72ee006` (`Replace TaskDeck branding with FlowPath assets`, 2026-05-15), before the later The Voice work.

## Primary FlowPath artwork

- `brand/flowpath-icon-square.png` — transparent 512×512 mark-only icon.
- `brand/flowpath-mark-square.png` — historical mark alias; identical bytes to `flowpath-icon-square.png`.
- `brand/flowpath-icon.png` — 1536×1024 mark artwork on the soft gradient background.
- `brand/flowpath-mark.png` — historical mark alias; identical bytes to `flowpath-icon.png`.
- `brand/flowpath-logo-full.png` — 1536×1024 mark plus the “FlowPath” wordmark.
- `brand/flowpath-logo.png` — historical logo alias; identical bytes to `flowpath-logo-full.png`.

## App icons

- `app-icons/icon.png` — 512×512 app icon.
- `app-icons/apple-icon.png` — 180×180 Apple touch icon.
- `app-icons/favicon.ico` — favicon containing 16×16, 32×32, and 48×48 variants.

No application code or current branding was changed; this is an asset archive only.
